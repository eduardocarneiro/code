# Python W3Schools Tutorial - Learning Path

This repository tracks my journey of learning Python from the ground up through hands-on practice, based on the official [W3Schools Python Tutorial](https://www.w3schools.com/python/). Every directory contains line-by-line code snippets written, tested, and documented to build a strong foundation in programming, aimed at supporting future automation and engineering tasks in cloud and infrastructure environments (DevOps/SRE).

## 📂 Directory Overview

Below is an overview of the concepts and topics covered in each directory of this repository:

### 🚀 Getting Started & Basics

* **`01-python-get-started`**: Initial setup, verifying Python installation, and environment execution.
* **`02-python-syntax`**: Core Python syntax rules, code block structure, and indentation conventions.
* **`03-python-output`**: Displaying output and formatted data using the `print()` function.
* **`04-python-comments`**: Best practices for writing single-line and multi-line comments.

### 📦 Data Types & Variables

* **`05-python-variables`**: Variable declaration, assignment techniques, and scope rules.
* **`06-python-data-types`**: Checking and understanding Python built-in data types using `type()`.
* **`07-python-numbers`**: Working with integers (`int`), floating-point numbers (`float`), and complex numbers.
* **`08-python-casting`**: Explicit type conversion between different data types (e.g., converting `str` to `int`).
* **`09-python-strings`**: String manipulation, slicing, formatting, concatenation, and useful string methods.
* **`10-python-booleans`**: Logical values (`True`/`False`) and boolean evaluation in expressions.
* **`11-python-operators`**: Utilizing arithmetic, assignment, comparison, logical, identity, and membership operators.

### 📚 Data Structures (Collections)

* **`12-python-lists`**: Creating, modifying, slicing, and operating on ordered, mutable lists.
* **`13-python-tuples`**: Working with immutable, ordered tuple collections.
* **`14-python-sets`**: Unordered sets, deduplication, and mathematical set operations (union, intersection, difference).
* **`15-python-dictionaries`**: Key-value data mapping (essential for JSON processing and API responses).

### 🔀 Control Flow & Logic

* **`16-python-if-else`**: Conditional logic and decision-making structures (`if`, `elif`, `else`).
* **`17-python-match`**: Structural pattern matching (`match-case`) for multi-branch control flows.
* **`18-python-while-loops`**: Condition-based iteration with `while` loops, `break`, and `continue`.
* **`19-python-for-loops`**: Iterating over sequences, lists, strings, and other iterable objects using `for` loops.

### ⚙️ Functions, Modules & Advanced Concepts

* **`20-python-functions`**: Defining reusable code blocks, handling positional/keyword arguments, default values, and return statements.
* **`21-python-range`**: Generating sequence bounds and controlled numerical ranges with `range()`.
* **`22-python-arrays`**: Basic array usage and sequence handling in Python.
* **`23-python-iterators`**: Understanding iterators, iterables, and `__iter__()` / `__next__()` mechanics.
* **`24-python-modules`**: Creating, importing, and modularizing code across multiple files.
* **`25-python-dates`**: Handling dates, timestamps, and time formatting with the `datetime` module.
* **`26-python-math`**: Built-in math functions and advanced mathematical operations using the `math` library.
* **`27-python-json`**: Parsing, encoding, and decoding JSON payloads (crucial for API integrations and Cloud automation).
* **`28-python-regex`**: Pattern matching, text search, and regex operations via the `re` module.
* **`29-python-pip`**: Package management, installing third-party libraries using `pip`.
* **`30-python-try-except`**: Robust exception handling and error management using `try`, `except`, `else`, and `finally`.
* **`31-python-string-formatting`**: Advanced string formatting techniques using `f-strings` and modifiers.
* **`32-python-none`**: Understanding the `None` type and handling null-like states in Python.
* **`33-python-user-input`**: Interactive CLI input handling using the `input()` function.
* **`34-python-virtual-env`**: Isolating project dependencies using Python virtual environments (`venv`).

## 🛠️ Requirements & How to Run

1. **Python 3.x** installed.
2. Clone the repository:
   ```bash
   git clone https://github.com/eduardocarneiro/code.git
    ```

Navigate to any directory and run a script using:
    ```bash 
    python <filename>.py
    ```
